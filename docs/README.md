# Project documentation

`docs/features/` contains durable descriptions and requirements for portfolio features. `docs/system/` contains cross-cutting system requirements. Consult the relevant documents when planning work, and update them when durable behavior or requirements change.

Proposed changes and implementation tickets are tracked in GitHub Issues. See [`docs/agents/issue-tracker.md`](agents/issue-tracker.md), [`docs/agents/triage-labels.md`](agents/triage-labels.md), and [`docs/agents/domain.md`](agents/domain.md) for the engineering workflow and documentation conventions.
