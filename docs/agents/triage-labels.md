# Triage Labels

Map the five canonical triage roles to this repo's issue labels.

| Label in Matt Pocock skills | Label in GitHub Issues | Meaning                                      |
| --------------------------- | ---------------------- | -------------------------------------------- |
| `needs-triage`              | `needs-triage`         | Maintainer needs to evaluate the issue       |
| `needs-info`                | `needs-info`           | Waiting on the reporter for more information |
| `ready-for-agent`           | `ready-for-agent`      | Fully specified, ready for an agent          |
| `ready-for-human`           | `ready-for-human`      | Requires human implementation                |
| `wontfix`                   | `wontfix`              | Will not be actioned                         |

When a skill mentions a triage role, use the corresponding label string in this table.
