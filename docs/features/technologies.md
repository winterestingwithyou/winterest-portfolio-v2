# Feature: Technologies and Categories

## Description

Technologies and categories describe the tools used across the portfolio. The public catalog groups tools by category, and project editors can associate technologies with projects.

## Requirements

- Public visitors can browse technologies grouped into categories, with each technology’s icon, brand color, and official link when provided.
- Technologies can belong to one or more categories. A technology marked as a featured tool can appear in the home page showcase.
- Editors, admins, and owners can create, edit, and delete technologies and categories, and can search and filter the dashboard lists.
- Category order can be set by the user. New categories receive the next available order by default, which the user can change.
- Technology and category slugs must be unique and suitable for use in URLs.
- Deleting a category removes its associations without deleting its technologies. Deleting a technology removes its category associations.
