# Feature: Initial Setup Status

## Description

Initial setup status guides a developer when the portfolio is not ready for normal use because its database setup is incomplete or no owner account exists.

## Requirements

- When required setup is incomplete, show a setup screen instead of the normal site and identify whether database setup or initial owner creation is needed.
- Provide setup guidance in English and Indonesian, with instructions for local and remote environments.
- Let developers copy the displayed setup command and check the setup status again.
- When database setup is complete and an owner account exists, make the normal site available.
