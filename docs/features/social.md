# Feature: Social Links

## Description

Social links lets the team manage the portfolio’s public social and communication links. Enabled links appear in the site’s footer, contact page, and about page.

## Requirements

- Editors, admins, and owners can add, change, reorder, enable, disable, and delete social links. Public visitors can view enabled links only.
- Support GitHub, LinkedIn, X, Instagram, Facebook, TikTok, YouTube, Discord, and Telegram.
- Each platform can have at most one configured link.
- Each link must use a valid HTTP or HTTPS URL.
- Public links appear in the configured order. Disabling a link hides it from public pages without deleting it.
