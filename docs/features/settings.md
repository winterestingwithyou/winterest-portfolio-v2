# Feature: Site Settings

## Description

Site settings let administrators manage the portfolio’s general information, social sharing and search metadata, downloadable CV links, and maintenance setting.

## Requirements

- Only owners and admins can view or change site settings. Editors cannot access this feature.
- Authorized users can manage the site name, tagline, contact email, and default language.
- Authorized users can set English and Indonesian page titles and descriptions, the page-title format, and the image used for social link previews.
- Show a preview of how a shared page will appear on X and LinkedIn as its metadata and image are edited.
- Store separate English and Indonesian CV links. Use the Indonesian CV for Indonesian visitors when available, and otherwise use the English CV.
- Owners and admins can enable or disable maintenance mode.
