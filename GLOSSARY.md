# Glossary

- **Cover Image**: A project's representative image, used in project listings and as the first image in its detail gallery when present.
- **Project gallery**: The ordered images shown in a project's detail view. It includes the Cover Image first when present, followed by additional Project Gallery Images. Images embedded in the project description are separate content.
- **Project Gallery Image**: An additional image selected for a project's detail gallery, beyond its Cover Image. It has an order and alternative text for each supported language.
